CopperFS

Free, MIT-licensed filesystems for the Amiga.

Filesystem directory

  • OFS / FFS

    CopperFFS

    Old File System and Fast File System disks. Read and write DOS0 and DOS1 volumes, and read DOS2–DOS5 variants.

    →
  • SFS / SFS2

    CopperSFS

    Smart File System disks, including the updated SFS2 format. TRST journaling, handler builds and SFS preview packages.

    →
  • CNFS

    CopperNova

    An experimental extent-based format for Amiga hard disks. File and partition limits, block sizes and test coverage.

    →
